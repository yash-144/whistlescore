# Product Proposal

## What is the product, and who uses it?
WhistleScore is an anonymous workplace safety and hazard reporting platform designed for employees in high-stakes and regulated environments (such as aviation, healthcare, chemical processing, and energy). It allows verified workers to submit incident severity ratings (+1, +3, +5 points) to an immutable, publicly verifiable company hazard score without fear of retaliation or exposure.

## Why Midnight specifically?
On transparent blockchains (like Ethereum or Cardano), all transactions expose the caller's address, transaction graph, and timestamp, making employee identification trivial via metadata correlation. Midnight's dual-state architecture uniquely solves this: the Compact smart contract validates the employee's authorization witness (`secret_token`) entirely inside the local browser zero-knowledge prover, updating only the aggregate public hazard counter. Observers can audit that every hazard score increment was generated by a genuine authorized employee, while the whistleblower's identity remains mathematically concealed.

## Data Model
| Data Point | Type | Disclosed To |
|---|---|---|
| `counter` (Cumulative hazard score) | Public ledger | Everyone (On-chain observers, auditors, public) |
| `step` (Incident severity increment) | Disclosed circuit input | Everyone (Included in public transaction data) |
| `secret_token` (Authorization credential) | Private witness | No one (Processed strictly inside local ZK prover) |
| `submitter_address` (Employee wallet) | Shielded state | No one (Shielded by Midnight's ZK transaction model) |

## Mainnet Feasibility
Yes, WhistleScore is architected with a lightweight Compact circuit that requires minimal on-chain state (`Uint<32>`) and low in-browser proof latency. For Mainnet deployment by Level 6, the authorization mechanism can be extended from a shared witness to nullifier-based Merkle tree membership proofs (preventing duplicate submissions) and decentralized credential issuance via Midnight's native shielded tokens.
